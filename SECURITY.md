# Security Policy

Chinese version: [SECURITY.zh-CN.md](./SECURITY.zh-CN.md)

## Supported Versions

SACP is currently experimental.

| Version | Supported |
|---|---|
| v0.1-alpha | Yes |

## Reporting Security Issues

Please open a private report if GitHub security advisories are enabled, or contact the repository owner through GitHub.

Do not open a public issue that contains:

- API keys
- access tokens
- credentials
- private local paths
- private logs
- private customer or project data

## Project Boundary

SACP is a protocol kit and reference checker. It does not execute the underlying agent task, guarantee correctness, or provide legal/compliance certification.

## Safe Example Policy

Use synthetic examples whenever possible. If a real workflow sample is used, remove private names, local paths, credentials, and raw private data.
