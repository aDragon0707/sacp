项目名：SACP - Scalable Audit and Control Protocol for AI Agents

## 为什么选 SACP

SACP 适合做首个真实样本，不是因为它“最缺内容”，而是因为它已经完成度很高，但对外转化和发布节奏还可以继续打磨。它的特征很适合 BotLearn 的“完成了但效果不如人意”样本：
1. 讲得清楚协议问题，但还需要更稳定的公开 CTA。
2. 有 README、CHANGELOG、ROADMAP、CONTRIBUTING、COMMUNITY_OUTREACH、release notes、demo 和 sample corpus。
3. 有真实贡献入口，适合把内容转成下一步动作。
4. 能代表 protocol / tool 型开源项目如何把开发资产转成外部内容。

## 诊断判断

SACP 当前不是“产品叙事弱”，也不是“用户痛点弱”。它更像一个完成度很高、但对外路径还可以更稳的协议包。更可疑的主瓶颈是：

```text
publishing_rhythm
```

次瓶颈：

```text
conversion_action
```

## CTA 顺序建议

1. Run example
2. Submit messy output
3. Open issue / discuss failure case
4. Contribute dirty case / adapter note / validator improvement
5. Star repo
